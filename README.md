# 타로롱 ☾

타로카드 78장의 의미를 찾아보고, 스프레드를 골라 직접 카드를 뽑아볼 수 있는 웹 앱이에요.
마스코트 **롱이**가 친근한 말투로 안내하고, "밤하늘 젤리" 톤으로 새로 그린 전용 카드 78장을 씁니다.

> 현재 단계: 프로젝트 스캐폴딩과 카드 일러스트 78장 + 뒷면 완료. 다음은 카드 의미 텍스트 작성이에요.

## 주요 기능

| 화면                         | 내용                                                                | 상태           |
| ---------------------------- | ------------------------------------------------------------------- | -------------- |
| 홈 `/`                       | 롱이 인사, 오늘의 카드(기기·날짜 기준), 스프레드 진입               | 뼈대           |
| 도감 `/cards`                | 78장 그리드, 메이저/수트 필터, 이름·키워드 검색                     | 그리드 완료    |
| 카드 상세 `/cards/:id`       | 정/역방향 의미, 주제별(연애·일·금전·조언) 의미, 이전/다음 카드      | 카드·이동 완료 |
| 뽑기 `/draw`, 결과 `/result` | 원카드·쓰리카드·연애운·켈틱 크로스, 부채꼴 덱에서 고르기, 해석 조합 | 예정           |

- 로그인·저장 없음. 접속할 때마다 새로 뽑아요(오늘의 카드용 랜덤 시드 하나만 브라우저에 저장).
- 해석은 카드·자리·주제별 문장 조각을 조합하고, 전체 요약은 규칙(메이저 비율, 많이 나온 수트 등)으로 만들어요.

## 기술 스택

| 영역       | 사용 기술                                                                |
| ---------- | ------------------------------------------------------------------------ |
| 프레임워크 | React 19, TypeScript 6.0                                                 |
| 라우팅     | React Router 8 (framework mode, SPA + prerender)                         |
| 빌드       | Vite 8                                                                   |
| 스타일     | Tailwind CSS 4, 폰트 자체 호스팅(@fontsource: Jua, Gowun Dodum, DM Mono) |
| 품질       | ESLint 10, Prettier 3, Vitest 5                                          |
| 배포       | Vercel (정적 배포)                                                       |

## 시작하기

Node.js 22 이상이 필요해요. 환경 변수는 없어요.

```bash
npm install
npm run dev        # 개발 서버
npm run build      # 프로덕션 빌드 + prerender → build/client
npm run preview    # 빌드 결과를 Vercel과 같은 규칙으로 로컬에서 확인 (http://localhost:4173)
```

| 명령                              | 설명                                   |
| --------------------------------- | -------------------------------------- |
| `npm run typecheck`               | 라우트 타입 생성 + `tsc`               |
| `npm run lint` / `lint:fix`       | ESLint                                 |
| `npm run format` / `format:check` | Prettier                               |
| `npm test`                        | Vitest 단위 테스트                     |
| `npm run cards`                   | 카드 일러스트 SVG 78장 + 뒷면 재생성   |
| `npm run icons`                   | 파비콘에서 `apple-touch-icon.png` 생성 |

## 기술적 하이라이트

- **SPA + prerender**: 홈·도감·카드 상세 78장은 빌드할 때 내용이 채워진 HTML로 미리 만들어요.
  첫 화면이 빠르고, JS를 실행하지 않는 크롤러(네이버, 카카오톡 링크 미리보기 등)도 카드별 제목·설명을 읽을 수 있어요.
  랜덤이 들어가는 뽑기·결과 화면은 SPA로 동작해요.
- **코드로 그린 카드 78장**: `scripts/cards/`의 생성 스크립트가 공통 부품(젤리 캐릭터, 컵·완드·소드·펜타클, 말 등)을
  조합해 SVG를 만들어요. 장당 약 6.5KB, 전체 약 500KB. 카드 뒷면은 180° 회전 대칭이라 역방향이 티 나지 않아요.
- **Vercel과 같은 로컬 미리보기**: `vite preview`는 prerender 경로에 홈 HTML을 내줘서 화면이 두 겹으로 그려지는 문제가 있어
  Vercel과 같은 서빙 규칙의 작은 서버(`scripts/preview.mjs`)를 씁니다.

## 카드 그림에 대해

카드 구성과 상징은 1909년판 라이더-웨이트-스미스 덱(Pamela Colman Smith 그림, 퍼블릭 도메인)을 바탕으로 했고,
그림은 이 프로젝트에서 새로 그렸어요. "Rider-Waite"는 상표라 앱 이름·브랜딩에는 쓰지 않아요.
